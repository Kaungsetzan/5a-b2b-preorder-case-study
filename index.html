Overview

Full platform — designed, developed, and shipped solo

5A Goldsmith is a gold jewellery business in Myanmar that needed a modern way for their B2B customers — other business owners and their staff — to browse products and place preorders remotely.

I designed and built the entire system: a cross-platform mobile app for customers, and a web-based admin dashboard for the business to manage everything from a single interface.

The project required understanding local constraints deeply — unreliable internet in Myanmar, a customer base unfamiliar with digital ordering, and a business that needed tight control over inventory and communication.

There are no in-app payments. Orders are fulfilled and settled offline. The app focuses on browsing, preordering, and direct communication.

Key Decisions

Solving real problems, not just technical ones

01

PIN checkout instead of OTP

Myanmar has unreliable mobile connectivity, making SMS or email OTP verification impractical. I replaced the standard flow with a shared PIN — customers enter it to confirm their intent. This solved the connectivity problem and reduced accidental orders placed by business staff, which the client specifically needed. If an order is still incorrect, customers can chat directly with the business inside the app.

02

Two completely separate authentication systems

Customers authenticate via Supabase Auth using synthetic email addresses. Admins authenticate through a custom bcrypt system against a separate table, receiving a signed HMAC token valid for 14 days — no Supabase Auth involved. This kept admin access fully isolated and prevented any cross-contamination between user types.

03

Real-time customer chat

Customers can message the business directly from the mobile app. To avoid exposing individual admin identities — since multiple staff members use the dashboard — all admin replies appear from a single unified sender. Messages are delivered in real time via Supabase Realtime, with connection backoff handling built in for poor network conditions.

04

Push notification system

Customers receive push notifications via Expo's notification service whenever an admin replies to their message or updates the status of an order. This removes the need for customers to manually check the app. Per-user notification preferences allow each customer to control which events trigger a push, with separate toggles for chat messages and order status updates.

05

Gold weight calculations done right

Gold in Myanmar is measured in a traditional unit system — kyat, pe, and yway. Floating-point arithmetic causes rounding errors that compound in pricing. I implemented all weight and fee calculations using integer arithmetic, isolated in a single shared package used by both the mobile app and the admin dashboard, so the logic is defined once and never duplicated.
